# linear-regression-gradient-descent
# 📈 Linear Regression with Gradient Descent (From Scratch)

This project implements linear regression from scratch using gradient descent optimization without relying on machine learning libraries.

## 📌 Project Overview
The notebook demonstrates:
- Manual implementation of linear regression
- Gradient descent optimization
- Mean Squared Error (MSE) loss function
- Training loop and convergence monitoring
- Visualization of fitted regression line
- Visualization of MSE over training iterations

## 🛠 Technologies Used
- Python
- NumPy
- pandas
- matplotlib
- Jupyter Notebook
